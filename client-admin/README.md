# Anyoka Eats Admin (client-admin)

Standalone CRA app for internal admin. No links to user client or backend yet.

- Install: `npm install`
- Dev: `npm start` (default at http://localhost:3000)
- Build: `npm run build`

Branding follows the main app via local copies of tokens and base styles.

> Production: serve on a separate subdomain (e.g., admin.yourdomain.com) and protect with SSO/MFA.
